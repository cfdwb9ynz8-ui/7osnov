# 7 Основ

Сайт строительной компании «7 Основ»: дома под ключ в ипотеку, Ставропольский край.

Статический сайт без сборки: `index.html`, `styles.css`, `script.js`, изображения в `img/`. Чтобы посмотреть локально, откройте `index.html` в браузере.

Настройки — в начале `script.js` (объект `CONFIG`): цена за м², телефон и `formEndpoint` — адрес для приёма заявок с формы. Пока `formEndpoint` пуст, заявки никуда не отправляются.
